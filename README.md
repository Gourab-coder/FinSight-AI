# FinSight AI

An educational credit-risk classification project built around the supplied
loan application dataset. It includes an executed modeling notebook, a fitted
calibrated classifier, reusable inference and portfolio-analysis helpers, and
a Streamlit dashboard.

> **Important:** This project is not validated for real lending. Do not use
> model outputs to approve or reject applicants, price loans, identify fraud,
> or make other consequential decisions. Do not enter real personal or
> financial information.

## Project contents

- `notebooks/01_NoteBook_Credit_Risk_Project.ipynb` — data exploration,
  feature preparation, model selection, calibration, evaluation, and artifact
  creation.
- `data/raw/credit_risk_dataset.csv` — application features and the
  `loan_status` outcome label.
- `models/credit_risk_model.joblib` — fitted calibrated classifier, threshold,
  risk-band cutoffs, and ordered feature names generated by the notebook.
- `src/predict.py` — validated inference helpers that follow the saved
  model's input schema.
- `src/risk_analytics.py` — portfolio label summaries, global model feature
  importance, and hypothetical expected-loss calculations.
- `frontend/app.py` — Streamlit portfolio, single-row demo, model-details,
  feature-importance, and loss-scenario views.
- `reports/model_evaluation.md` — recorded held-out evaluation and limitations.
- `tests/` — unit tests for inference and risk-analysis helpers.

## Requirements and setup

Use Python 3.13 and the versions in `requirements.txt`, including the XGBoost
version compatible with the serialized model.

PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The dashboard expects the dataset at
`data/raw/credit_risk_dataset.csv` and the fitted model at
`models/credit_risk_model.joblib`.

## Run the dashboard

```powershell
.\.venv\Scripts\python.exe -m streamlit run frontend\app.py
```

The dashboard reads the supplied dataset and trusted local model. Individual
demo inputs and predictions are processed in memory and are not written to a
database or file. Do not expose this demo publicly with real applicant data.

## Run tests

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Reproduce model training

Open and run `notebooks/01_NoteBook_Credit_Risk_Project.ipynb` using the
project environment. It saves the calibrated model and its threshold,
risk-band cutoffs, and ordered feature names to
`models/credit_risk_model.joblib`. The model uses `loan_status` as its target;
label 1 is the dataset's default label and is not an input feature.

See [reports/model_evaluation.md](reports/model_evaluation.md) for the recorded
held-out results and limitations. The dashboard reads thresholds and feature
names from the current artifact; it does not calculate evaluation metrics
from the full dataset.

### Artifact compatibility and safety

Keep scikit-learn, XGBoost, Joblib, and related package versions aligned with
`requirements.txt` when loading the artifact. Joblib files can execute code
while loading, so load only the trusted artifact produced by this project—not
files from untrusted sources.

## Data, target, and privacy notes

The model estimates the probability of the supplied dataset's
`loan_status = 1` label. This is a dataset outcome, not a validated
real-world probability of default. The dashboard shows descriptive label
rates and global feature importance; neither is causal or an explanation for
an individual estimate. Its expected-loss view uses hypothetical assumptions
and is not a learned model output.

Avoid entering sensitive or real borrower information.
