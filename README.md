# FinSight AI

An educational credit-risk analysis project built around a **synthetic**
Indian loan-application dataset. It includes a documented notebook workflow,
a calibrated scikit-learn model, reusable inference and risk-analysis helpers,
and a Streamlit dashboard.

> **Important:** This project is not validated for real lending. Do not use
> its outputs to approve or reject applicants, price loans, identify fraud,
> or make other consequential decisions. Do not enter real personal or
> financial information.

## Project contents

- `notebooks/01_data_understanding.ipynb` — data shape, quality, target,
  missingness, and documented exclusions.
- `notebooks/02_credit_risk_eda.ipynb` — descriptive exploratory analysis.
- `notebooks/03_feature_engineering.ipynb` — leakage-aware splits and
  train-fitted preprocessing.
- `notebooks/04_anomaly_detection.ipynb` — exploratory Isolation Forest and
  domain checks; anomaly scores are not event probabilities.
- `notebooks/05_supervised_modeling.ipynb` — reproducible model selection,
  calibration, threshold selection, evaluation, and artifact creation.
- `src/predict.py` — validated, stateless prediction and EMI helpers.
- `src/risk_analytics.py` — descriptive subgroup summaries, global feature
  importance, and hypothetical expected-loss calculations.
- `frontend/app.py` — Streamlit portfolio, assessment, performance,
  explanation, and scenario views.
- `models/credit_risk_model.joblib` — fitted pipeline and inference/evaluation
  metadata generated by Notebook 5.
- `reports/model_evaluation.md` — concise evaluation and limitations.
- `tests/` — unit tests for inference and risk-analysis helpers.

## Requirements and setup

Use Python 3.13 and the included virtual environment instructions. Core
dependencies are pinned in `requirements.txt` to match the environment used to
create and test the serialized model artifact.

PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The repository includes the synthetic CSV and fitted model. The dashboard
expects them at `data/raw/finsight_ai_india_synthetic_5000.csv` and
`models/credit_risk_model.joblib`, respectively.

## Run the dashboard

```powershell
.\.venv\Scripts\python.exe -m streamlit run frontend\app.py
```

The app loads the local synthetic portfolio and trusted model artifact. It
does not write individual borrower inputs or predictions to a database or
file. Do not expose this demo publicly with real applicant information.

## Run tests

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Reproduce model training

Open and run the notebooks in numeric order using the project environment.
Notebook 5 writes the fitted pipeline and its metadata to
`models/credit_risk_model.joblib`. The notebook defines a stratified
70% / 15% / 15% train/validation/test split, tunes on training data, selects
the model and decision threshold on validation data, then evaluates the
held-out test set.

The selected artifact uses a calibrated Random Forest. Logistic Regression
and scikit-learn Histogram Gradient Boosting were also evaluated; XGBoost was
not installed or declared in the project environment. See
[reports/model_evaluation.md](reports/model_evaluation.md) for the recorded
test metrics and limitations.

### Artifact compatibility and safety

The serialized artifact was created with the dependency versions pinned in
`requirements.txt`. Keep those versions aligned when loading it; retrain and
regenerate the artifact after intentional dependency or model changes.
Joblib files can execute code while loading, so load only the trusted artifact
produced by this project—not files from untrusted sources.

## Target, feature, and privacy notes

The supervised target is `target_default_within_12m`; label 1 denotes the
dataset's observed 12-month default event. It is an outcome label, never a
model input. Application identifiers and fields with unclear timing or
meaning are excluded. The model calculates EMI and post-loan debt-to-income
from application inputs and derives
`requested_loan_to_annual_income = requested_loan_amount_inr / (12 * monthly_net_income_inr)`.

The loss view is a hypothetical calculation:
`expected loss = event probability × LGD assumption × EAD assumption`.
Its probability, loss-given-default, and exposure values are assumptions, not
validated measures learned from the available synthetic dataset.

Individual assessment inputs are processed in memory for inference and are
not saved by the app. Avoid entering sensitive or real borrower information.
